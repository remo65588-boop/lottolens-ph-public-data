Archive coverage and methodology

The live LottoLens PH archive publishes a separate, date-stamped coverage report with the current record count, per-game coverage, collection method, provenance notes, freshness checks, and known limitations.

Read the dataset coverage and methodology note and the live PCSO Results Data Coverage Report before citing archive totals. Counts can change after new draws, while the schedule files in this repository change only when normal draw rules materially change.

Responsible use

This resource is provided for public information, data checking, education, and research. It does not predict future results or guarantee a win. LottoLens PH is an independent information project and is not affiliated with or endorsed by PCSO.
